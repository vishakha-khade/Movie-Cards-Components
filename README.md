# Movie Cards

This is a simple React project where movie information is displayed in individual movie cards.

The movie data is stored separately in a JSON file and is displayed dynamically using React. This project helped me practice working with components, props, map(), and displaying data from JSON.

## Features

- Displays multiple movie cards
- Movie data stored in a JSON file
- Dynamic rendering using map()
- Reusable Movie component
- Displays movie name, image, description, director, and rating
- Responsive card layout
- Simple and clean UI

## Technologies Used

- React
- JavaScript
- CSS
- JSON
- Vite

## What I Practiced

While building this project, I practiced:

- Creating reusable React components
- Passing data using props
- Using map() to render multiple cards
- Working with JSON data
- Using images with React
- Applying CSS Flexbox
- Creating responsive layouts
- Understanding the relationship between parent and child components
